# SimpleChat

A real-time messaging application built with Django.

## Features

- User registration
- Login and logout
- Private conversations
- Group conversations
- Real-time messaging
- PostgreSQL database
- Redis channel layer
- Django Channels
- Responsive interface

## Requirements

- Python 3
- Docker Desktop
- VS Code (recommended)

## Installation

1. Install Python 3.
2. Install Docker Desktop.
3. Open the project folder in Terminal.
4. Run:

```bash
chmod +x setup_mac.command
./setup_mac.command
